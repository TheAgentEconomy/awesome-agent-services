## What Is An Agent Service?

An agent service is a tool, API, feed, MCP server, payment rail, or infrastructure layer that an AI agent can discover, call, pay for, or use inside a workflow.

This list is especially interested in:

- agent-payable services
- x402 and HTTP 402 payment infrastructure
- MCP servers
- agent-facing APIs
- useful data feeds
- business, finance, travel, commerce, media, and developer services

## Legend

- `MCP` - Model Context Protocol server or connector
- `x402` - Supports or relates to x402 payments
- `API` - Agent-callable HTTP API or hosted endpoint
- `Paid` - Requires payment, credits, or usage fees
- `OSS` - Open source repository available

## Contributing

Contributions are welcome and encouraged. Whether you are fixing a typo, adding a useful service, or improving a description, your help is appreciated.

Add one bullet under the most relevant category.

Format:

```markdown
- [Name](URL) - One factual sentence. Tags: MCP, x402, API, Paid, OSS.
```

Example:

```markdown
- [Example Service](https://example.com) - Agent-callable API for useful work. Tags: API, Paid.
```

Please keep it simple:

- One service per pull request.
- One bullet per service.
- Use a stable public URL.
- Keep the sentence factual, not promotional.
- Include tags at the end.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full contribution guide.
